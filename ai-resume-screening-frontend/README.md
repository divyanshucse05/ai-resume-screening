# AI Resume Screening & Candidate Shortlisting — Frontend

React + Vite frontend for managing job roles, uploading PDF/TXT resumes, screening candidates with LLMs, and exporting shortlisted candidates.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server (proxies `/api` to `http://localhost:5000`):
   ```bash
   npm run dev
   ```
3. For live deployment (Vercel / Netlify), set `VITE_API_URL` to your deployed backend URL and rebuild:
   ```bash
   npm run build
   ```
